 Interview Tracker Web App

A full-stack, minimalist web application to help you prepare for interviews, track job applications, and evaluate your progress.

## How to run the application manually:

1. Open a terminal, navigate to `backend`, and run `npm install` followed by `npm start` (or `node server.js`). This will start the backend on port 5000.
2. Open a second terminal, navigate to `frontend`, run `npm install`, and then `npm run dev`.
3. Open your browser to the URL provided by Vite (usually `http://localhost:5173`).
